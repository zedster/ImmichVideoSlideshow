# Android Home Video Channel

This folder contains a new Android feature copy of the tvOS `HomeVideoChannel` app.

It mirrors the same main product areas:

- Immich server setup and persisted config
- Random or sequential video playback
- ExoPlayer-backed full-screen playback
- Metadata overlays and info panel
- Favorite and hide actions against the Immich API
- Local SQLite cache for synced metadata and playback stats
- Settings and library stats surface

The local environment here does not have Java or Gradle installed, so this project was scaffolded but not built in this session.
