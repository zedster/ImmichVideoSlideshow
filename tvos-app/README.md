# tvOS App

Native Apple TV app for Immich Video Slideshow.

## Run in Xcode

1. Open `tvos-app/ImmichVideoChannel/ImmichVideoChannel.xcodeproj` in Xcode.
2. Select scheme `ImmichVideoChannel`.
3. Select an Apple TV simulator or physical device.
4. Build and run.

## Notes

- Configure Immich URL and API key in the app setup view.
- Recommended for large libraries with local SQLite caching.
