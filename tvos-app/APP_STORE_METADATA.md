# App Store Metadata

## App Name
Home Video Channel

## Subtitle
Continuous playback from your server

## Description
Home Video Channel turns your Apple TV into a continuous stream of videos from your personal media library.

The app connects to an Immich server and plays videos from your existing collection.

Immich is an open-source self-hosted photo and video management platform. This app acts as a client that connects to a user's own Immich server and streams videos stored there.

Features:
- Continuous playback of videos
- Randomised playback
- Minimum video length filter
- Optimised for large libraries
- Designed specifically for tvOS

## App Review Notes
This app is a tvOS client for users who run their own Immich server.

Immich is an open-source self-hosted photo and video management platform. Users generate their own API key from their personal server and enter it in the app to authenticate.

The app does not sell digital content, subscriptions, or unlock features through external payment systems. The API key is only used to authenticate with the user's existing server and access their personal video library.

The app streams videos stored on the user's own server.
