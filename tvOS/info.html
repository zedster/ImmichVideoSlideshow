Immich Video Slideshow for tvOS

Native Apple TV app for full-screen Immich video playback with local SQLite caching, flexible playback ordering, sync controls, and remote-friendly overlays.

SwiftUI tvOS 16+ Immich API SQLite Cache

Core Features

  • Immich URL and API key setup with in-app connection test.
  • Playback modes: Random, Sequential Oldest -> Newest, Sequential Newest -> Oldest.
  • Favorites-only filtering and in-player favorite toggle.
  • Playback tuning: crossfade, preload window, queue size, minimum duration.
  • Hide-forever action with explicit warning and confirmation.

Sync + Local Data

  • Sync controls include force sync and progress/error status.
  • SQLite tables: videos, sync_state, watch_events.
  • Stats include watched counts, favorites, hidden counts, and top metadata groups.
  • Sequential progress is persisted and resumed across launches.
  • Automatic startup sync can run when cache is empty.

Build in Xcode

  1. Open tvOS/xCodeProj/ImmichVideoChannel/ImmichVideoChannel.xcodeproj.
  2. Select scheme ImmichVideoChannel.
  3. Build and run on Apple TV device or tvOS Simulator.

Support + FAQ

Need help? Start with these common questions, then open an issue if you are still blocked.

Open Support Issue
1. What is the minimum tvOS version?

The app targets tvOS 16+ and is designed for Apple TV device and simulator on that baseline.

2. Why does the app say my Immich URL is invalid?

Use the full base URL including protocol, for example https://immich.example.com or http://192.168.1.10:2283.

3. Where do I get the API key?

Create a personal API key in your Immich account settings, then paste it in the app setup screen.

4. Why are no videos playing after setup?

Run Force Sync Now, confirm your account has video assets, and verify filters like favorites-only or minimum duration are not excluding everything.

5. What does Hide Forever do?

It hides the asset in Immich itself, not just locally. Unhide must be done from the Immich web interface.

6. Is playback order remembered between launches?

Yes. In sequential modes, last playback progress is stored in SQLite and resumed automatically.

7. How do I improve playback smoothness?

Increase preload window and queue size, keep crossfade enabled, and reduce random batch size if your server/network is constrained.

8. Is my API key sent to browser JavaScript?

No. In tvOS mode, requests are made natively and the key stays local on Apple TV in app storage.

9. Can I reset watch/progress data?

Yes. Use the reset playback progress option in settings if you want sequential modes to restart from the beginning.

10. Where should I report bugs or request features?

Use the GitHub Issues page linked above and include your tvOS version, app settings, and relevant log output.
